# Dastoor Restaurant — Enhanced

A responsive Next.js + Tailwind CSS restaurant website redesign for Dastoor.

## Included

- Premium light theme using warm white, black and a new light-gray stone palette.
- Responsive navigation with mobile menu.
- GSAP-powered reveal, floating and anchor smooth-scroll effects loaded from CDN.
- Hero "How it works" video modal with a burger-making YouTube embed.
- Full menu page with 100 dishes, search and category filters.
- Enhanced menu cards with badges, ratings, prices and hover states.
- Dedicated About page.
- Dedicated Contact page with working client-side success state.
- Google Maps embed for Khokherki, Sialkot Road, Gujranwala, Punjab, Pakistan.
- Responsive layouts across mobile, tablet, laptop and large desktop sizes.

## Run

```bash
npm install
npm run dev
```

The project uses the existing package versions from the supplied project. GSAP is loaded through `next/script`, so there is no extra npm dependency for the animation layer.
